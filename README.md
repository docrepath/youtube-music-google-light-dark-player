# YouTube Music — Google Light + Dark Player

A custom **light theme for YouTube Music** designed around a clean Google-style interface while keeping the **bottom music player dark** for better control visibility and contrast.

## Why this theme?

YouTube Music is predominantly dark by default. This style provides a light, Google-style interface while deliberately retaining a dark bottom player so playback controls remain high-contrast and easy to read.

## Features

- Light YouTube Music interface
- Google-style white/light-gray surfaces
- Dark bottom player with white controls
- Preserves album artwork and thumbnail visibility
- Rounded mood/category chips
- Light sidebar, navigation and search areas
- Improved readability of Home-page headings and controls
- CSS-only: no JavaScript and no bundled YouTube Music assets

## Installation with Stylus

1. Install the [Stylus browser extension](https://github.com/openstyles/stylus).
2. Open the `.user.css` file from this repository, or use the raw-file link below.
3. Stylus should display its installation page.
4. Click **Install style**.

### Direct installation

After the repository is published, the direct Stylus installation link will be:

`https://raw.githubusercontent.com/docrepath/youtube-music-google-light-dark-player/main/YouTubeMusic-Google-Light-Dark-Player.user.css`

The repository is intended to be hosted at:

`https://github.com/docrepath/youtube-music-google-light-dark-player`

## Scope

The style applies only to:

`https://music.youtube.com/`

## Compatibility

YouTube Music is a frequently changing web application. The stylesheet relies on YouTube Music's current DOM structure and custom elements, so a future site redesign may require selector or layout updates.

If something breaks after a YouTube Music update, please open an issue with:

- browser and version
- Stylus version
- what changed or stopped working
- a screenshot, if useful
